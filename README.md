# 🌐 Portfolio Personale & Servizi Web

Benvenuto nel repository del mio sito web personale! Questo progetto è concepito come una vetrina interattiva per presentare le mie competenze, la mia identità come developer e i servizi di sviluppo web su misura che offro a professionisti e piccole attività.

---

## 🛠️ Tech Stack & Architettura

Il sito è sviluppato con uno stack moderno orientato a prestazioni ultra-rapide, codice pulito e reattività:

- **Frontend:** [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling:** [CSS]
- **Componenti UI:** [shadcn/ui](https://ui.shadcn.com/)
- **Qualità del Codice:** [Oxlint](https://oxc.rs/) / [ESLint](https://eslint.org/)
- **Version Control:** Git & GitHub

---

## 🚀 Servizi Offerti

Attraverso la piattaforma offro soluzioni web personalizzate:

* 💻 **Siti Vetrina e Landing Page:** Strutture monopagina e multipagina ottimizzate per conversioni, velocità e impatto visivo.
* ⚡ **Ottimizzazione SEO & Performance:** Architettura snella e tempi di caricamento ridotti al minimo per scalare i motori di ricerca.
* 🎨 **UI/UX Design Responsivo:** Interfacce curate nei dettagli, fluide e perfettamente usabili da qualsiasi dispositivo (desktop e mobile).
* 🛠️ **Manutenzione & Supporto:** Restyling, aggiornamenti periodici ed estensione di funzionalità su progetti esistenti.
